## このブログについて

ソフトウェアエンジニアリングに関する技術ブログです。日々の開発で得た知見やTipsを記録しています。

## 技術スタック

このブログは以下の技術で構築されています:

- **記事**: Markdown (YAML front matter)
- **ビルド**: Python + Pandoc
- **ホスティング**: GitHub Pages
- **コードハイライト**: Prism.js
- **図表**: Mermaid
- **検索**: Fuse.js (クライアントサイド全文検索)

## ソースコード

このブログのソースコードは [GitHub](https://github.com/dysksh/blog) で公開しています。
